# 02 - 引导语收成单一常量

**What to build:** 纯 prefactor，**用户可见行为一字不变**。

agent 在多处提示用户该怎么说出自己的意图，示例文案"选3张发朋友圈"在 session 层散落**五处**各写了一遍。票 08 要把这句示例扩写成能引导用户说出题材偏好的形式（"选三张有景有人、表情活泼的照片发朋友圈"），五处分头改必漏。

先把它们收敛成一个常量，让后面那次改写只需要动一个地方。"Make the change easy, then make the easy change."

**Blocked by:** None - can start immediately.

**Status:** done（`bc778e3`，2026-08-01 合入 main）

- [x] 五处示例文案统一引用同一个常量（落地成 `_intent_hint_example()`，理由见下）
- [x] 用户看到的文字与改动前逐字相同
- [x] 既有 session 层测试全绿，无需修改断言

**实现与票面的一处出入：五处并非完全相同。** 去重追问那一处（`_render_dedup_followup_gate`）的上文是"告诉我留几张"，例子跟着用的是"**留**3张发朋友圈"而不是"选"。若把五处统一到一个裸常量上，就会悄悄改掉用户看到的一个字，与本票"一字不变"的验收标准冲突。

因此收敛成一个带 `verb` 参数的函数 `_intent_hint_example(verb="选")`（`agent/session/consumer.py`），示例本身仍然只有一份，票 08 那次改写照样只动这一个函数体，本票的目的不受影响。

顺带给去重追问那一处补了条断言钉住"留"字。此前没有任何测试覆盖它，是收敛过程中最容易被顺手统一成"选"的地方。既有断言一条未改。
